- **[👀 Agent Eyes](https://github.com/webkubor/vite-plugin-agent-eyes)** — A Vite runtime telemetry layer for coding agents. It turns API errors, browser state and proxy details into evidence an agent can read, so it can locate and verify a fix on its own.<br/><sub>MIT · [npm](https://www.npmjs.com/package/vite-plugin-agent-eyes) · <img src="https://img.shields.io/github/stars/webkubor/vite-plugin-agent-eyes?style=flat-square&label=%E2%98%85&color=6e7681" alt="stars" height="14" /></sub>

- **[🔐 Kyvault](https://github.com/webkubor/kyvault)** — A local secret vault built for AI workflows: encrypted on your machine, tools fetch secrets by alias, and the agent never handles the plaintext.<br/><sub>Rust · MIT · [crates.io](https://crates.io/crates/kyvault) · <img src="https://img.shields.io/github/stars/webkubor/kyvault?style=flat-square&label=%E2%98%85&color=6e7681" alt="stars" height="14" /></sub>

- **[🖥️ DSH Env Inspector](https://github.com/webkubor/dsh-env-inspector)** — Checks your dev environment, CLIs, plugins and ports, making environment problems visible and fixable without exposing secret values.<br/><sub>[npm](https://www.npmjs.com/package/@dsh-plugins/dsh-env-inspector) · <img src="https://img.shields.io/github/stars/webkubor/dsh-env-inspector?style=flat-square&label=%E2%98%85&color=6e7681" alt="stars" height="14" /></sub>

- **[🔄 Vite Refresh Guard](https://github.com/webkubor/vite-plugin-refresh-guard)** — Stops users from staying on a stale build after you deploy. Pick silent reload, prompted reload or a blocking wait in one line of config; the core works with Vue and React.<br/><sub>MIT · [npm](https://www.npmjs.com/package/vite-plugin-refresh-guard) · <img src="https://img.shields.io/github/stars/webkubor/vite-plugin-refresh-guard?style=flat-square&label=%E2%98%85&color=6e7681" alt="stars" height="14" /></sub>

### Bloom: a design system where visual judgment can be tested

<p align="center">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="./assets/bloom-dark.svg" />
    <img src="./assets/bloom-light.svg" width="100%" alt="Six Bloom Morandi colors used directly as text only reach 2.3 to 3.3:1 contrast; keeping hue and chroma and solving only lightness brings each to 4.5:1." />
  </picture>
</p>

- **[Bloom for Typora](https://github.com/webkubor/typora-Bloom-theme)** — 24 themes for long-form writing and immersive reading; included in the [official Typora theme gallery](https://theme.typora.io/theme/Bloom/).<br/><sub><img src="https://img.shields.io/github/stars/webkubor/typora-Bloom-theme?style=flat-square&label=%E2%98%85&color=6e7681" alt="stars" height="14" /></sub>

- **[Bloom for DSH](https://github.com/webkubor/dsh-bloom-theme)** — The same Morandi visual language brought to DeepSeek Harness, with light and dark themes and OKLCH palettes.<br/><sub><img src="https://img.shields.io/github/stars/webkubor/dsh-bloom-theme?style=flat-square&label=%E2%98%85&color=6e7681" alt="stars" height="14" /></sub>

- **[contrast-guard](https://github.com/webkubor/contrast-guard)** — Checks color contrast in CI with OKLCH support; when a pair fails, it tells you which way to adjust.<br/><sub><img src="https://img.shields.io/github/stars/webkubor/contrast-guard?style=flat-square&label=%E2%98%85&color=6e7681" alt="stars" height="14" /></sub>

**Not just pretty colors**: every palette runs on two rails. The true Morandi color only fills large atmospheric areas; text and buttons use a version whose lightness was solved for contrast. WCAG constraints calibrate the themes, so design choices can be checked automatically. *Taste, made testable.*
